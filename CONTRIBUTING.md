# Contributing to Veredas

## Development Workflow

1. **Branch naming:** `feat/<scope>`, `fix/<scope>`, `chore/<scope>`
2. **Commit messages:** Conventional Commits — `feat(leads): add note pagination`
3. **PRs:** Target `main`. All CI checks must pass before merge.

---

## Backend (Laravel 11)

### Running locally
```bash
cd backend
php artisan serve
```

### Running tests
```bash
php artisan test                  # all tests
php artisan test --filter Auth    # single suite
php artisan test --coverage       # with HTML coverage (requires Xdebug)
```

### Code style
```bash
./vendor/bin/pint                 # Laravel Pint (PSR-12)
```

### Adding a new endpoint
1. Create a controller in `app/Http/Controllers/Api/`
2. Register routes in `routes/api.php` under the correct auth + role middleware group
3. Add `->paginate(25)` on any index() that returns a collection
4. Write a corresponding Feature test in `tests/Feature/`
5. Document the endpoint in `docs/API.md`

## Frontend (Next.js 14 — Turborepo)

### Running locally
```bash
cd veredas
pnpm dev          # starts all apps in watch mode
pnpm dev --filter website   # only the admin frontend
```

### Adding a shared component
1. Add the component to `packages/ui/src/index.ts`
2. Export it from the package root
3. Import in apps via `import { MyComponent } from '@veredas/ui'`

### Adding a shared type
1. Define the type in `packages/types/src/index.ts`
2. Import in apps via `import type { MyType } from '@veredas/types'`

### Code style
```bash
pnpm lint         # ESLint across all packages
pnpm typecheck    # tsc --noEmit across all packages
```

## Security

- Never commit credentials, `.env` files, or `seed-credentials.txt`
- Token storage: **HttpOnly cookie only** — do NOT use `localStorage`
- All write endpoints require `role:ADMIN,OPERATOR` middleware
- Throttle limits: login `10/min`, writes `30/min`, user management `20/min`
- Run `composer audit` and `pnpm audit` before each release
